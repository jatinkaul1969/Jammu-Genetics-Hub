# Brand assets for the Social Studio posters

Put your logo here as **`logo.png`** (a square or wide PNG with a transparent background works best, at least 400 px tall).
When the file exists, every poster uses it instead of the gold "JGH" tile. When it does not, posters fall back to the tile.

Nothing else needs to change: the poster maker looks for this file each time it draws a poster
(see `src/lib/social/logo.ts`).
