Fonts used to render social-media posters (src/lib/social). All three families are
licensed under the SIL Open Font License 1.1 — free to use and embed.

- Fraunces (Undercase Type) — headlines
- IBM Plex Sans (IBM) — body text
- Noto Sans Devanagari (Google) — Hindi text

Files come from the @fontsource packages (latin, latin-ext and devanagari subsets, woff).
The latin-ext files are needed for the rupee sign (₹).
